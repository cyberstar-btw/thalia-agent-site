About Thalia Agent

Thalia Agent is a planned open-source project by cyberstar-btw for small B2B teams that send proposals and need to keep track of conversations with no reply.

The planned agent would help a person notice a conversation that may need follow-up, decide what to do, and prepare a draft for the person to review and send themselves.

This is a project in development. The agent is not available yet.
